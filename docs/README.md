Τα Markdown είναι τοπικά αρχεία τεκμηρίωσης και το υπάρχον .htaccess αποκλείει την απευθείας ανάγνωσή τους από HTTP. Ανοίξτε τα από τον φάκελο ή δώστε αντίγραφα στον υπεύθυνο εγκατάστασης.
