Απλούστερη ενημέρωση GitHub — 30/10/2026

Η κάρτα «Ενημερώσεις από GitHub» περιλαμβάνει όλη τη διαδικασία:
1. Έλεγχος τώρα — χωρίς πρόσθετη εισαγωγή κωδικού.
2. Λήψη και έλεγχος υπογραφής — χωρίς πρόσθετη εισαγωγή κωδικού.
3. Προεπισκόπηση και «Backup και εγκατάσταση» στην ίδια κάρτα — μία εισαγωγή κωδικού, χωρίς πληκτρολόγηση ΕΝΗΜΕΡΩΣΗ.

Προϋπόθεση είναι ενεργή σύνδεση διαχειριστή. CSRF, υπογραφή, συμβατότητα, hash, προστασία από αλλαγμένη προεπισκόπηση και backup παραμένουν. Αλλαγή έμπιστου κλειδιού, χειροκίνητο ZIP, επαναφορά και απεγκατάσταση διατηρούν τις ξεχωριστές επιβεβαιώσεις τους.

Εφάπαξ εφαρμογή σε υπάρχον σχολείο:
- Κρατήστε αντίγραφο των υπαρχόντων admin/maintenance.php και includes/github_updates.php και backup της εφαρμογής.
- Ανεβάστε ΠΡΩΤΑ το includes/github_updates.php στον υπάρχοντα includes.
- Ανεβάστε ΜΕΤΑ το admin/maintenance.php στον υπάρχοντα admin.
- Αντικαταστήστε μόνο αυτά τα δύο ομώνυμα αρχεία. Όχι ολόκληρους φακέλους. Καμία αλλαγή σε config, κλειδιά, διόρθωση sessions ή βάση.
- Ανανεώστε τη σελίδα συντήρησης. Αν υπάρχει ελεγμένο πακέτο από την παλιά οθόνη, κατεβάστε το ξανά από την κάρτα GitHub ώστε να εμφανίζεται στη σωστή ροή.

Το ZIP δεν εισάγεται στον updater: αλλάζει το προστατευμένο admin/maintenance.php και χρειάζεται εφάπαξ FTP. Δεν αλλάζει τον αριθμό έκδοσης. Δεν καταργείται η προστασία του μηχανισμού συντήρησης από αυτόματη αντικατάσταση.

Τα ασφαλή μηνύματα αποτυχίας ελέγχου αποθηκεύονται και παραμένουν ορατά μετά την ανανέωση. Διακρίνονται DNS, σύνδεση, timeout, TLS και HTTP κωδικοί χωρίς εμφάνιση URLs με μυστικά, tokens ή ωμών server logs. Το «Έλεγχος τώρα» επαναλαμβάνει την προσπάθεια.
