# Κοινή εμφάνιση καρτελών

Το κεντρικό σημείο αλλαγών είναι το `assets/css/theme-tokens.css`. Φορτώνεται αυτόματα από το `style.css` σε όλες τις σελίδες που χρησιμοποιούν το κοινό stylesheet. Δεν χρειάζεται αλλαγή HTML ή PHP για τις παρακάτω ρυθμίσεις.

| Χαρακτηριστικό | Μεταβλητή |
|---|---|
| Βασικό χρώμα / hover / απαλό φόντο | `--ui-accent`, `--ui-accent-hover`, `--ui-accent-soft` |
| Βασικό κουμπί / hover / κείμενό του | `--ui-button-bg`, `--ui-button-hover`, `--ui-button-text` |
| Φόντο σελίδας / καρτέλας | `--ui-page-bg`, `--ui-panel-bg` |
| Κείμενο / δευτερεύον κείμενο / περίγραμμα | `--ui-text`, `--ui-muted`, `--ui-border` |
| Στρογγύλεμα καρτελών / μικρών πλαισίων | `--ui-panel-radius`, `--ui-control-radius` |
| Εσωτερική απόσταση desktop / κινητού | `--ui-panel-padding`, `--ui-panel-padding-mobile` |
| Απόσταση ομάδων πλοήγησης | `--ui-panel-gap` |
| Μέγεθος τίτλων / σκιά | `--ui-panel-title-size`, `--ui-panel-shadow` |
| Αποστάσεις / μέγεθος γραμμάτων καρτελών πλοήγησης | `--ui-tabs-gap`, `--ui-tab-padding`, `--ui-tab-font-size` |
| Περιθώρια κεφαλίδας / σώματος πτυσσόμενης ομάδας | `--ui-group-padding`, `--ui-group-body-padding` |

Παράδειγμα: για πιο συμπαγείς καρτέλες, ορίστε `--ui-panel-padding: 20px` και `--ui-panel-radius: 10px`. Οι αντίστοιχες τιμές σκοτεινού θέματος βρίσκονται στο ίδιο αρχείο, στο `[data-theme="dark"]`. Διατηρήστε ευανάγνωστη αντίθεση κειμένου/φόντου. Τα χρώματα επιτυχίας, προειδοποίησης και διαγραφής παραμένουν ξεχωριστά.

Το `assets/css/shared-surfaces.css` ορίζει τους κοινούς κανόνες εμφάνισης. Χρησιμοποιεί τις υπάρχουσες `.card`, `.card-title`, `.nav-tabs`, `.nav-tab`, ομάδες προτύπων email και σχολικών ετών. Για νέα υπομενού χρησιμοποιήστε `.app-tabs` και `aria-current="page"` στον ενεργό σύνδεσμο. Για νέα πτυσσόμενη ομάδα χρησιμοποιήστε `<details class="app-disclosure"><summary>Τίτλος</summary><div class="app-disclosure-body">…</div></details>`: το native τρίγωνο και η πλοήγηση πληκτρολογίου διατηρούνται.

Οι σελίδες κρατούν τη δική τους διάταξη, πλάτος, grid, πίνακες και επιχειρησιακή λειτουργία. Για διαφορετική πυκνότητα σε συγκεκριμένη ενότητα προτιμήστε τοπική μεταβλητή, π.χ. `.my-panel { --ui-panel-padding: 18px; }`, αντί νέου κανόνα `padding` ή inline style. Inline οπτικές τιμές παλιών σελίδων μπορεί να υπερισχύουν· κατά την ανανέωσή τους αντικαθίστανται σταδιακά από κοινές classes/variables.

Μετά από αλλαγές σε έκδοση παραγωγής ενημερώστε το cache version του `style.css` και των imports του ώστε να μη χρησιμοποιηθούν παλιές τιμές από τον browser.
