> Για το νέο πακέτο easy δεν χρειάζεται άρση αποκλεισμού .htaccess ή token περιβάλλοντος. Αν το install.php επιστρέφει 403, ελέγξτε αν είναι ήδη εγκατεστημένο, αν έχετε το σωστό κλειδί INSTALLATION-KEY.txt και HTTPS. Οι παρακάτω οδηγίες χειροκίνητου token αφορούν παλαιότερα πακέτα ή ειδική ρύθμιση server.

# Αντιμετώπιση προβλημάτων

| Σύμπτωμα | Τι ελέγχουμε |
|---|---|
| install.php → 403 | Στο νέο easy πακέτο ελέγξτε κλειδί από INSTALLATION-KEY.txt και HTTPS. Υπάρχον database.php ή installed.lock κλειδώνει τον οδηγό. Στα παλιά πακέτα ισχύει και αποκλεισμός .htaccess. |
| Μήνυμα μη εξουσιοδοτημένου εγκαταστάτη | APP_INSTALL_TOKEN ή ιδιωτικό APP_INSTALL_TOKEN_FILE στο περιβάλλον του web server, μήκος μυστικού και αναγνωσιμότητα αρχείου. Απομακρυσμένη πρόσβαση χρειάζεται HTTPS. |
| Λείπουν παράμετροι παραγωγής | Πραγματικό config που φορτώνεται, APP_BASE_URL και όλα τα DB constants. Το config/database.production.php δεν φορτώνεται αυτόματα. |
| Σφάλμα σύνδεσης βάσης | Host, port, βάση, δικαιώματα, pdo_mysql και σωστό prefix. Μην εμφανίζετε πραγματικό κωδικό σε screenshots. |
| Αποτυχία XLS/XLSX | PHP 8.2+, extensions και ακέραιο includes/spreadsheet/vendor. Ελέγξτε τις απαιτήσεις στο CONFIGURATION/INSTALLATION. |
| Υπερβολικά μεγάλο upload | upload_max_filesize, post_max_size, PHP memory/time limits και τα εσωτερικά όρια της εφαρμογής. Τοπικό αποθηκευμένο backup ή CLI για μεγάλα restore. |
| Δεν εισάγονται μαθητές | Επικεφαλίδες Α.Μ., Επώνυμο μαθητή, Όνομα μαθητή, αριθμητικό Α.Μ. και σωστό ενεργό έτος. |
| Δεν εμφανίζεται τμήμα | Αναθέσεις εκπαιδευτικού στο ενεργό έτος και ρόλος. |
| Η ώρα είναι κλειδωμένη | Ιδιοκτησία καταχώρησης, ρόλος και δικαιολογημένες απουσίες. Μην παρακάμπτετε τους ελέγχους. |
| Δεν παραδίδονται email | Έγκυροι παραλήπτες, SMTP/TLS, εξωτερικό master key, πραγματική ενεργοποίηση αποστολών και ιστορικό. Δοκιμή σε ελεγχόμενο παραλήπτη. |
| Η συντήρηση δεν ενεργοποιείται | Υπαρκτός εγγράψιμος ιδιωτικός φάκελος εκτός document root, μοναδικός ανά εγκατάσταση. |
| Restore/DROP απορρίπτεται | Δικαιώματα συντήρησης, γνωστοί πίνακες, εξωτερικά foreign keys, ταυτότητα εγκατάστασης και έμπιστη καταγραφή/hash. |
| HTTP 503 μετά από αποτυχία | Η εφαρμογή έμεινε σε συντήρηση για ανάκτηση. Κρατήστε source/rescue backups και ακολουθήστε MAINTENANCE.md. Μην διαγράφετε απλώς state.json. |
| HTTP 410 | Έχει καταγραφεί απεγκατάσταση. Ανάκτηση μέσω CLI από υπεύθυνο, όχι διαγραφή lock και επανεκτέλεση εγκαταστάτη. |

Δώστε στην υποστήριξη την ώρα συμβάντος, τη σελίδα, την ενέργεια, την έκδοση εγκατάστασης και το ακριβές μη ευαίσθητο μήνυμα. Μην αποστέλλετε master key, κωδικούς, tokens ή πλήρη στοιχεία μαθητών.
