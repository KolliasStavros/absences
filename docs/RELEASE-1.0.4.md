# Έκδοση 1.0.4 — πλήρης συγχρονισμός ενημερώσιμων αρχείων

## Αιτία

Ο τοπικός κώδικας συμφωνούσε με τον κώδικα του αποθετηρίου, αλλά τα προηγούμενα πακέτα ενημέρωσης δεν μετέφεραν όλες τις διαφορές από την παλιά εγκατάσταση της 28/10. Έλειπαν ενημερώσεις σε dashboard, header/footer, ειδοποιήσεις και προεπισκόπηση, ιστορικό, διαχείριση μαθητών, προβολή τμήματος, API και εμφάνιση. Η 1.0.4 διορθώνει αυτή την παράλειψη διανομής.

## Περιεχόμενα και όρια

Κάθε υπογεγραμμένο πακέτο περιέχει 838 ενημερώσιμα αρχεία του τρέχοντος δημόσιου κώδικα, αντί για ελλιπή διαφορά μεταξύ στιγμιοτύπων. Υπάρχουν πακέτα από 1.0.0, 1.0.1, 1.0.2 και 1.0.3. Δεν υπάρχουν SQL migrations ή διαγραφές. Το schema της πραγματικής παλιάς διανομής είναι byte-for-byte ίδιο με το σημερινό.

Παραμένουν αμετάβλητα config/*, install.php, .htaccess, admin/maintenance.php, includes/lifecycle.php, includes/lifecycle_guard.php, includes/lifecycle_restore.php και bin/restore_backup.php, σύμφωνα με τις προστασίες του υπάρχοντος updater. Αυτό διατηρεί τις τοπικές ρυθμίσεις και τη διόρθωση συνεδριών του σχολείου. Η νέα οθόνη συντήρησης μεταφέρεται μέσω της ήδη τεκμηριωμένης υπογεγραμμένης μονάδας, χωρίς αντικατάσταση του προστατευμένου entry point.

Στην παλιά διανομή οι προστατευμένοι lifecycle/restore έχουν επιπλέον διαφορά για υποστήριξη ονομάτων backup με κενά, ενώ .htaccess/install.php διαφέρουν για το τοπικό εργαλείο εγκατάστασης. Αυτές οι προστατευμένες μεταβολές δεν εφαρμόζονται από αυτό το πακέτο. Οι αλλαγές UI και κανονικής λειτουργίας περιλαμβάνονται. Ένα αμετάβλητο αρχείο τεκμηρίωσης βιβλιοθήκης με κενά στο όνομα διατηρείται στην εγκατάσταση, καθώς η διαδρομή του δεν υποστηρίζεται από τον strict verifier. Επιβεβαιώθηκε ίδιο στην παλιά διανομή και στον σημερινό κώδικα.

## Εφαρμογή

Από Ενημερώσεις & Απεγκατάσταση: Έλεγχος τώρα → Λήψη και έλεγχος υπογραφής → προεπισκόπηση → Backup και εγκατάσταση. Αν ο παλιός updater ζητά επιπλέον ΕΝΗΜΕΡΩΣΗ, ακολουθήστε την παλιά οθόνη για αυτή τη μετάβαση. Μετά ανανεώστε με Ctrl+F5. Το δημόσιο κλειδί παραμένει ίδιο. Μην ανεβάζετε ZIP νέας εγκατάστασης πάνω σε ενεργό σχολείο.

## Επαλήθευση

Ανακατασκευάστηκε η πραγματική διανομή 28/10 με το μικρό payload 1.0.3 και επιβεβαιώθηκε ότι το dashboard παρέμενε παλιό. Εφαρμόστηκε η πλήρης 1.0.4 μέσω HTTP με τον παλιό verifier. Επαληθεύθηκαν backup, έκδοση 1.0.4, αμετάβλητα προστατευμένα αρχεία και όλα τα 838 payload files έναντι του τοπικού κώδικα. Πέρασαν 13 σελίδες (dashboard, καρτέλες, ιστορικό, μαθητές, καθηγητές, τμήματα, εισαγωγή, ρυθμίσεις, βοήθεια, διαγνωστικά, προβολή/βοήθεια εκπαιδευτικού και άδεια), live API, responsive assets, XLS και εκτύπωση. Και τα τέσσερα πακέτα έγιναν δεκτά από τον παλιό verifier. Χρησιμοποιήθηκαν μόνο συνθετικά δεδομένα. Δεν αποτελεί οπτική πιστοποίηση κάθε συσκευής ή hosting.
