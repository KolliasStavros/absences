# Έκδοση 1.0.3 — ενιαία ενημέρωση GitHub

Η νέα οθόνη εγκαθίσταται από τον υπάρχοντα updater GitHub χωρίς FTP. Διατίθενται υπογεγραμμένα πακέτα από 1.0.0, 1.0.1 και 1.0.2. Χρησιμοποιείται το ίδιο έμπιστο δημόσιο κλειδί.

Πάτησε Έλεγχος τώρα και Λήψη και έλεγχος υπογραφής. Για αυτή τη μετάβαση ακολούθησε την παλιά οθόνη: αν ζητά ΕΝΗΜΕΡΩΣΗ και κωδικό στην παλιά κάρτα, συμπλήρωσέ τα και εφάρμοσε την 1.0.3 με backup. Ανανέωσε τη σελίδα. Στη νέα ροή έλεγχος, λήψη, προεπισκόπηση και Backup και εγκατάσταση βρίσκονται στην ίδια κάρτα GitHub. Κωδικός ζητείται μόνο στην τελική εγκατάσταση, χωρίς πληκτρολόγηση λέξης.

Το προστατευμένο admin/maintenance.php παραμένει αμετάβλητο και λειτουργεί ως authenticated entry point που ήδη αναγνωρίζει ο lifecycle guard. Το ενημερώσιμο includes/github_updates.php φορτώνει τη μονάδα includes/maintenance_controller.php μόνο όταν εκτελείται αυτό το συγκεκριμένο entry point. Η μονάδα επανελέγχει admin και αποκλείει απευθείας πρόσβαση. Δεν εισάγονται αυθαίρετα include paths. Η μονάδα και ο loader επαληθεύονται μέσα στο υπογεγραμμένο πακέτο. Μελλοντικές αλλαγές ροής γίνονται στη μονάδα, χωρίς αντικατάσταση entry point/guards/config. Οι συναρτήσεις της μονάδας έχουν διαφορετικά ονόματα από τις παλιές, για συμβατότητα PHP.

Παραμένουν CSRF, υπογραφή, συμβατότητα, έλεγχος προεπισκόπησης, κωδικός πριν την εγκατάσταση και επαληθευμένο backup. Η χειροκίνητη μεταφόρτωση ZIP είναι ξεχωριστή. Δεν υπάρχουν SQL migrations, διαγραφές ή αλλαγές config/ιδιωτικών κλειδιών. Περιλαμβάνονται όλες οι εξαρτήσεις Καρτελών Απουσιών και ο helper ιδιωτικών συνεδριών.

Μια αρχική 1.0.0 χωρίς καθόλου updater GitHub εξακολουθεί να χρειάζεται αρχική ενεργοποίηση ή χειροκίνητη μεταφόρτωση του κατάλληλου υπογεγραμμένου πακέτου. Αν το hosting δεν επιτρέπει σύνδεση λόγω μη εγγράψιμου αρχικού session.save_path, προηγείται η ειδική διόρθωση συνεδριών. Το προστατευμένο config δεν παρακάμπτεται.

Έλεγχος: πραγματικός παλιός updater 1.0.2 σε προσωρινή βάση εγκατέστησε την υπογεγραμμένη 1.0.3. Επαληθεύθηκαν backup, καταγεγραμμένη έκδοση και αμετάβλητα admin/maintenance.php, config/config.php, includes/lifecycle.php, lifecycle_guard.php και lifecycle_restore.php. Η νέα μονάδα φόρτωσε από το παλιό entry point, ο έλεγχος δεν ζήτησε κωδικό, η εγκατάσταση απαίτησε κωδικό και η απευθείας πρόσβαση επέστρεψε 404. Η ενιαία ροή ελέγχθηκε επιπλέον προηγουμένως με 16 HTTP και 3 ελέγχους σφαλμάτων. Χρησιμοποιήθηκαν μόνο συνθετικά δεδομένα.
