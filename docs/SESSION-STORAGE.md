Διόρθωση αποθήκευσης συνεδριών σε hosting με μη εγγράψιμο session.save_path

Το διαγνωστικό έδειξε σταθερό cookie αλλά απώλεια session/CSRF, files handler και μη εγγράψιμο προεπιλεγμένο φάκελο. Η εφαρμογή χρησιμοποιεί πλέον ιδιωτικό υποφάκελο sessions μέσα στον ήδη ρυθμισμένο APP_MAINTENANCE_DIR. Δεν χρησιμοποιεί δημόσιο φάκελο, δεν απενεργοποιεί CSRF/TLS/HttpOnly και δεν περιέχει SQL ή στοιχεία σχολείου.

Εγκατάσταση από υπεύθυνο hosting/FTP:
1. Κατεβάστε αντίγραφο του ΥΠΑΡΧΟΝΤΟΣ config/config.php στον υπολογιστή σας και φυλάξτε backup εφαρμογής και ιδιωτικών ρυθμίσεων.
2. Ανεβάστε ΠΡΩΤΑ το includes/session_storage.php στον υπάρχοντα φάκελο includes της εφαρμογής.
3. Ανεβάστε ΜΕΤΑ το config/config.php στον υπάρχοντα φάκελο config, αντικαθιστώντας ΜΟΝΟ το ομώνυμο config.php. Μην αντικαταστήσετε τον φάκελο config.
4. Μην αλλάξετε database.php, private-config.php, local.php, maintenance.php, installed.lock ή τα ιδιωτικά κλειδιά/configs. Το config.php του πακέτου είναι γενικός loader, δεν περιέχει διαπιστευτήρια. Αν ο υπεύθυνος hosting έχει προσαρμόσει ειδικά αυτό το αρχείο, διατηρήστε τις προσαρμογές και ενσωματώστε μόνο το require/prepareAbsencesSessionStorage πριν από την εκκίνηση συνεδρίας.
5. Ανοίξτε ξανά τη σελίδα σύνδεσης με HTTPS και συνδεθείτε. Οι παλιές συνεδρίες ενδέχεται να απαιτήσουν νέα σύνδεση.
6. Διαγράψτε το προσωρινό session-check-...php από το site. Αυτό δοκιμάζει το προεπιλεγμένο hosting storage, όχι τη νέα ιδιωτική αποθήκευση της εφαρμογής, οπότε δεν χρησιμοποιείται για επαλήθευση μετά τη διόρθωση.

Προϋπόθεση: υπάρχει APP_MAINTENANCE_DIR σε ιδιωτικό εγγράψιμο φάκελο, όπως ήδη απαιτεί η λειτουργία backup/update. Δεν αλλάζει η έκδοση ή η βάση. Δεν είναι ZIP για μεταφόρτωση στον updater· τα δύο συγκεκριμένα αρχεία μεταφέρονται με FTP.

Εναλλακτικά ο υπεύθυνος μπορεί να ορίσει APP_SESSION_DIR σε ιδιωτική ρύθμιση, με πλήρη διαδρομή υπάρχοντος/δημιουργήσιμου φακέλου εκτός web root. Τα προσαρμοσμένα session handlers δεν αντικαθίστανται. Μην βάλετε δικαιώματα 777 και μην αποθηκεύετε sessions σε δημόσιο φάκελο.

Έλεγχος 30/10/2026: HTTP σύνδεση με συνθετικό admin και σκόπιμα μη διαθέσιμο αρχικό session.save_path. Επιτυχία σταθερού CSRF σε επαναλαμβανόμενα GET, αποδοχή έγκυρου CSRF, απόρριψη λανθασμένου CSRF, σύνδεση, προστατευμένη σελίδα, ιδιωτική αποθήκευση και HttpOnly. Χωρίς χρήση δεδομένων σχολείου.
